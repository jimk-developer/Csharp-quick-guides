Storing Many Values Under One Name

Many programming tasks involve working with a whole collection of related values at once, not just a single number or string. C# handles this with arrays: structures that group many values of the same type under one variable name. This guide covers how arrays are declared and initialized, how to access and search their contents, how to work with several related arrays together, the built-in methods C# provides for sorting and searching, arrays with more than one dimension, and how arrays behave inside GUI applications.

📚 Array Fundamentals

An array is a list of data items that all share the same data type and the same name, distinguished from one another only by their position in the list. Each individual data item stored in an array is called an array element.

Arrays are most useful for the opposite situation from storing just one value: they let a program manage many related values, such as every quiz score in a class or every item in an order, under a single variable name instead of creating a separate variable for each one.

Arrays Are Objects

In C#, arrays are objects, instances of the built-in System.Array class. Because an array is an object, it is created using the same new operator used to instantiate any other object, and once created, C# manages where that array lives in memory automatically; a program does not choose or control an array's specific memory location.

Indexes and Subscripts

Each array element is distinguished from the others by its index, also called a subscript: an integer enclosed in square brackets that indicates an element's position within the array. C# array subscripts are always zero-based, meaning the first element's subscript is 0, not 1. For an array with 15 elements, the valid subscripts run from 0 through 14, so the highest legal subscript is always one less than the array's total number of elements.

A subscript must be an integer, or an expression that evaluates to an integer; it cannot be a floating-point value or any other data type. This is exactly what makes arrays powerful in a loop: using a variable as the subscript, rather than a hardcoded constant, lets a single loop step through every element in order simply by changing that variable's value.

📝 Declaring and Initializing Arrays

Syntax: Declaring an Array

double[] weeklySales = new double[7];
bool[] attendanceFlags = new bool[20];

Declaring an array this way, without supplying values, creates an array of the specified size where every element automatically receives a default value based on the array's data type.

Array Type Default Element Value
Numeric (int, double, and similar) 0
char The null character, \u0000
bool false

Initializer Lists

An initializer list assigns a list of nondefault values to an array's elements at the moment it is declared, instead of relying on default values.

Syntax: Declaring and Initializing an Array Together

string[] shirtSizes = { "XS", "S", "M", "L", "XL" };
int[] winningNumbers = { 4, 17, 22, 38 };

Both statements above correctly declare an array and supply its initial values in a single step, with the values listed inside curly braces and separated by commas. Once declared this way, an array's size is fixed to however many values appear in the initializer list.

🎯 Accessing Array Elements

An individual array element is accessed by writing the array's name followed by that element's subscript in square brackets, such as shirtSizes[0] for the first element.

Example: Accessing a Specific Element

string[] rainbowColors = { "red", "orange", "yellow", "green", "blue", "indigo", "violet" };

Console.WriteLine("My favorite color is {0}", rainbowColors[4]);
// Displays: My favorite color is blue

The Length Property

Every array, as an instance of System.Array, automatically has a Length property that holds the total number of elements it contains. A loop that navigates through an entire array typically runs its subscript variable from 0 up through, but not including, Length.

Example: Looping Through an Array with Length

for (int i = 0; i < rainbowColors.Length; ++i)
{
    Console.WriteLine(rainbowColors[i]);
}
Comparing the loop control variable to the array's Length property, rather than to a hardcoded integer, means the loop automatically adjusts if the array's size ever changes. A hardcoded upper bound can silently become wrong, either skipping elements or causing an out-of-range error, the moment the array's actual size no longer matches that constant.

🔁 The foreach Loop

C# provides a dedicated foreach statement that cycles through every element of an array without using a subscript at all.

Syntax: A foreach Loop

foreach (string color in rainbowColors)
{
    Console.WriteLine(color);
}

The variable declared right after foreach, here color, is called the iteration variable. It automatically holds each array value in turn for one pass of the loop, without the program ever writing a subscript expression.

The foreach iteration variable is read-only: its value can be read and used, but it cannot be assigned a new value in a way that changes the underlying array element. Avoid using foreach when a loop needs to modify array elements as it goes, or whenever the loop body needs to know the current subscript itself, such as when displaying each element's position alongside its value; a traditional for loop is the right tool for either of those situations instead.

🔍 Searching Arrays

Sequential Search

A sequential search examines each element of an array in order, one after another, comparing it to a target value until either a match is found or the entire array has been checked. Sequential searches can be written using either a for loop or a while loop.

Example: A Sequential Search with a for Loop

string[] inventoryItems = { "wrench", "hammer", "pliers", "screwdriver" };
string requested = "pliers";
bool containsItem = false;

for (int count = 0; count < inventoryItems.Length; ++count)
{
    if (inventoryItems[count] == requested)
    {
        containsItem = true;
    }
}

A reasonable searching technique uses a loop that continues comparing elements until it either finds a match or reaches the end of the array, whichever happens first. If the loop completes and its subscript variable has reached a value equal to the array's Length, that outcome means the target value was never found anywhere in the array.

Improving Search Efficiency

Searching an array becomes inefficient whenever the code keeps examining elements after a match has already been found, since any comparisons made after that point are wasted work. A few strategies reduce unnecessary comparisons:

🥇

Most Common Items First

Arranging array elements so the values most likely to be searched for come first reduces the average number of comparisons a sequential search needs to perform.

🚪

Early Exit

Stopping the search loop as soon as a match is found, rather than continuing to check the remaining elements, avoids comparisons that can no longer change the outcome.

Example: A For Loop with an Early Exit

for (int count = 0; count < inventoryItems.Length; ++count)
{
    if (inventoryItems[count] == requested)
    {
        containsItem = true;
        break;
    }
}

Adding break immediately after a match is found is one straightforward way to exit a for loop early once the target has been located, rather than letting the loop run through every remaining element regardless.

Example: An Early-Exit Search with a While Loop

int count = 0;
bool found = false;

while (count < inventoryItems.Length && !found)
{
    if (inventoryItems[count] == requested)
    {
        found = true;
    }
    count++;
}

When using a while loop to search an array, include the "not yet found" condition as part of the loop's own test expression, alongside the subscript boundary check. This lets the loop stop naturally the moment a match is found, without needing a separate break statement.

Validating User Input Against a List

Storing a set of valid values in an array and then using a search loop to check whether user input matches one of them is a recommended, reliable strategy for validating that input, rather than writing a long chain of individual comparisons by hand.

🔗 Parallel Arrays

Parallel arrays are two or more arrays that share the same number of elements, where corresponding data is stored in elements that share the same subscript across each array. Accessing element 3 of one parallel array and element 3 of another retrieves two different pieces of information about the same underlying record.

Example: Parallel Arrays

int[] petIDs = { 101, 102, 103 };
string[] petNames = { "Bit", "Beau", "Tim" };
double[] adoptionFees = { 50.50, 75.35, 55.00 };

// Subscript 1 across all three arrays describes the same pet: Beau
Console.WriteLine("{0} (ID {1}): {2:C2}", petNames[1], petIDs[1], adoptionFees[1]);

Because petIDs, petNames, and adoptionFees are parallel arrays, subscript 1 identifies the same pet across all three: its ID, its name, and its adoption fee.

Range Matches

A range match uses an array of upper or lower limit values to determine which pair of limiting values a given number falls between, and a parallel array to hold the result that corresponds to each range.

Example: A Range Match with a Parallel Array

double[] weightLimits = { 5, 10, 20 };
double[] shippingFees = { 6.00, 8.50, 12.50, 15.80 };

double orderWeight = 12;
int tier = 0;

while (tier < weightLimits.Length && orderWeight >= weightLimits[tier])
{
    tier++;
}

Console.WriteLine("Shipping fee: {0:C2}", shippingFees[tier]);
// weightLimits marks the upper edge of each of the first three tiers;
// shippingFees has one extra element to cover everything above the last limit

Here, weightLimits holds the boundary values used to determine which tier an order's weight falls into, while the parallel array shippingFees holds the dollar amount that applies to each resulting tier.

🛠️ Built-in Array Methods

The System.Array class provides several static methods that perform common array operations without requiring you to write the underlying loop yourself.

Method Purpose
Array.Sort() Arranges an array's elements in ascending order, either numerically or alphabetically depending on the array's data type
Array.Reverse() Reverses the existing order of an array's elements without sorting them first
Array.BinarySearch() Finds the position of a target value by repeatedly splitting a sorted array in half

Example: Sort() and Reverse()

int[] prizeNumbers = { 42, 7, 19, 3 };

Array.Sort(prizeNumbers);
// prizeNumbers is now { 3, 7, 19, 42 }

Array.Reverse(prizeNumbers);
// prizeNumbers is now { 42, 19, 7, 3 }, reversed from its prior order
To display an array's elements in descending order, sort it first with Array.Sort() and then reverse that sorted result with Array.Reverse(). Calling Array.Reverse() alone only flips whatever order the elements were already in; it does not sort them.

Binary Search

Binary search locates a target value by repeatedly dividing a sorted array in half and discarding the half that cannot contain the target, continuing until an exact match is found or the search space is exhausted. Array.BinarySearch() is most appropriate when the array is already sorted and reasonably large, since binary search eliminates roughly half of the remaining elements from consideration with each comparison, making it far faster than a sequential search through a large sorted array.

Array.BinarySearch() only produces correct results on an array that has already been sorted in ascending order. Running it on an unsorted array can return an incorrect or misleading result, since the method's halving strategy assumes the data is already in order.

Calling Array Methods Without the Class Prefix

Adding a using static System.Array; directive near the top of a file allows methods such as Sort() and BinarySearch() to be called directly, without repeatedly typing the Array. prefix before each call.

🧮 Multidimensional and Jagged Arrays

Two-Dimensional (Rectangular) Arrays

A multidimensional array requires more than one subscript to access its elements. The most common form is the two-dimensional array, also called a rectangular array, which can be pictured as a table or matrix of rows and columns where every row has exactly the same number of columns.

Example: A Rectangular Array

double[,] quarterlyRevenue = {
    { 12000, 15000, 11000 },   // Store 1: Q1, Q2, Q3
    { 9800,  10200, 9600  },   // Store 2: Q1, Q2, Q3
    { 14300, 13800, 15100 }    // Store 3: Q1, Q2, Q3
};

// Store 2's Q2 revenue, accessed with two subscripts
Console.WriteLine(quarterlyRevenue[1, 1]);

Reading a statement like this, each inner set of braces represents one row, and the values within it represent that row's columns; the statement above creates a rectangular array with 3 rows and 3 columns. Data that naturally forms a consistent grid, such as a matrix with a fixed number of rows and an identical number of columns in every row, is a good candidate for a rectangular array rather than any other structure.

Jagged Arrays

A jagged array is a one-dimensional array whose elements are themselves one-dimensional arrays, possibly of different lengths. Unlike a rectangular array, a jagged array's "rows" do not need to be the same size as one another.

Example: A Jagged Array

int[][] seatsPerRow = new int[3][];
seatsPerRow[0] = new int[] { 1, 2, 3, 4 };
seatsPerRow[1] = new int[] { 1, 2 };
seatsPerRow[2] = new int[] { 1, 2, 3 };

// Access row 1's second seat number using two subscripts
Console.WriteLine(seatsPerRow[1][1]);
// Displays: 2

Notice that a jagged array element is accessed using two separate sets of square brackets, one for the outer array's subscript and one for the inner array's subscript, rather than a single comma-separated pair as with a rectangular array.

When a table of data naturally has the same number of columns in every row, such as a large matrix of numeric data with a fixed number of rows and columns, a rectangular array is usually the simpler and more natural fit. Reach for a jagged array only when the rows genuinely differ in length, such as varying numbers of seats in different rows of a theater.

🖱️ Arrays in GUI Applications

An event-handling method, such as a button's Click method, runs fresh each time its event occurs. Any variable declared inside that method, including an array, is created new and loses its previous values every time the method runs again.

If an array's values need to change based on user input across multiple separate events, such as accumulating a total every time a user clicks a button, that array must be declared outside of any single event-handling method, at the class level, rather than inside the method that reacts to the event. Declaring it inside the event method instead would reset the array back to its starting values every single time the event fired, discarding whatever had already been accumulated.

Example: An Array Declared at the Class Level

public partial class DonationForm : Form
{
    // Declared at the class level so it persists across every button click
    private double[] projectDonations = { 0, 0, 0, 0 };

    private void OkButton_Click(object sender, EventArgs e)
    {
        // Uses and updates projectDonations without recreating it
    }
}

Placing the declaration here, above any individual event method but still inside the class, means every event method in the class shares the same array instance and can both read from it and add to it without losing earlier updates.
