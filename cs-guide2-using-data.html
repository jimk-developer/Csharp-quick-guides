Working With Data in C#

Every C# program manipulates data, and that data has to live somewhere and be described in a way the compiler understands. This guide covers how to declare and use variables and constants, the built-in data types C# provides, how to format and display output, the operators used to work with values, how values convert between types, how characters and strings behave, how to define your own type-safe sets of constants, and how to accept input from a user.

📦 Variables and Constants

What Is a Variable?

A variable is a named location in computer memory that can hold different values at different points in time while a program runs. Before you can use a variable, you must declare it. A variable declaration names the variable and reserves storage for it by specifying its data type, which describes the format and amount of memory the value will occupy and what operations can be performed with it.

Syntax: Declaring and Initializing a Variable

int lapCount;
lapCount = 0;

// Declaration and initialization combined
int bestLapTime = 58;

Assigning a value to a variable at the same moment it is declared is called initialization. The equal sign (=) is C#'s assignment operator; it does not mean "equals" the way it does in math class, it means "store the value on the right into the variable on the left." An assignment is the act of storing a value into a variable.

Constants

A literal constant is a value, such as 58 or "finish line", written directly into your code. A named constant is an identifier that represents a value that cannot change once it is set. You create a named constant with the const keyword, and it must be initialized at the moment it is declared.

Syntax: Declaring a Named Constant

const int MAX_RUNNERS = 200;
const double TRACK_LENGTH_MILES = 0.25;
By convention, many C# programmers write named constant identifiers in screaming caps (all uppercase with underscores between words), as in MAX_RUNNERS. This convention makes constants easy to spot at a glance, though it is a style choice rather than a compiler requirement.
Once a value is declared const, it is immutable: any later attempt to assign it a new value is a compiler error. Choose const only for values that genuinely never change while the program runs.

🔢 Data Types

C# provides a set of built-in intrinsic types (also called simple types), each with a specific size and range. Intrinsic types fall into three main families: integral types, floating-point types, and the Boolean type.

Integral Data Types

The integral data types hold whole numbers, with no decimal component. They differ from one another by size (how much memory they occupy) and by whether they allow negative values.

Type Size Signed?
byte 8-bit Unsigned (0 and positive only)
sbyte 8-bit Signed
short 16-bit Signed
ushort 16-bit Unsigned
int 32-bit Signed
uint 32-bit Unsigned
long 64-bit Signed
ulong 64-bit Unsigned
char 16-bit Holds a single character, not a number
Because uint and ulong are unsigned, they cannot legally hold a negative value. Assigning -100 to a uint variable is a compiler error, not a value that silently becomes positive.

When you type a whole-number constant such as 58 directly into a C# program, its default data type is int unless you specify otherwise. Choose the smallest integral type that comfortably fits the values a variable will realistically hold; a byte, for example, is well suited to something like a person's age, which will never need a large range or a negative value.

Digit Separators

C# allows an underscore (_) as a digit separator inside a numeric literal, purely to improve readability. Digit separators are ignored by the compiler and do not change the value in any way.

Example: Digit Separators

int stadiumCapacity = 23_456_789;
// Identical in value to: 23456789

Floating-Point Data Types

The floating-point data types hold numbers with decimal positions and can represent varying numbers of significant digits, the digits in a number that carry meaning for its precision.

Type Approximate Precision Typical Use
float About 7 significant digits Lower-precision, smaller-memory scientific values
double About 15 to 16 significant digits The general-purpose default for most floating-point values
decimal 28 to 29 significant digits Money and other values requiring exact precision

Why decimal for Money?

Among the floating-point types, decimal offers greater precision and a smaller range than float or double, which makes it the right choice for financial and monetary calculations where rounding errors are unacceptable. A decimal literal is written with an m suffix, such as 19.99m.

A plain floating-point literal such as 19.99 defaults to type double unless you tell the compiler otherwise. To create a float literal, append an f suffix, as in 19.99f; to create a decimal literal, append m, as in 19.99m. Leaving off the suffix and assigning the literal directly to a float or decimal variable is a common source of compiler errors.

Scientific Notation

Very large or very small floating-point values may display in scientific notation, such as 9.32E-05. This means 9.32 multiplied by 10 raised to the -5 power, or 0.0000932. The letter E separates the significant digits from the power of ten.

The Boolean Type

A bool (Boolean) variable can hold only one of two values: true or false. A Boolean expression is any expression that evaluates to a Boolean value, most commonly the result of a comparison.

Syntax: Declaring a Boolean Variable

bool raceIsFinished = false;
bool personalRecordBroken = finishTime < previousBest;

🖨️ Console Output and Formatting

Three Ways to Combine Text and Variables

C# offers three common techniques for building output that mixes literal text with variable values.

➕

Concatenation

Join strings together with the plus (+) sign. Works but can become hard to read with many pieces.

🔢

Placeholders

Numbered positions like {0} inside a format string, filled in order by a list of values that follows.

🧵

String Interpolation

A $ prefix lets you embed variable names directly inside a string using curly braces.

Example: Three Techniques, Same Output

string racerName = "Maya";
int finishPlace = 3;

// Concatenation
Console.WriteLine(racerName + " finished in place " + finishPlace);

// Placeholders
Console.WriteLine("{0} finished in place {1}", racerName, finishPlace);

// String interpolation
Console.WriteLine($"{racerName} finished in place {finishPlace}");

A placeholder is a number enclosed in curly braces, such as {0}, that marks which value from the list following the format string belongs in that position of the output. A format string is the series of characters, including any placeholders, used to control the appearance of text output.

Alignment

A placeholder can include an alignment component, written as {index, width}. A positive width right-aligns the value within a column of that many characters; a negative width left-aligns it.

Example: Right-Aligned Columns

Console.WriteLine("{0,6}", "Yes");
Console.WriteLine("{0,6}", "No");
// Output:
//    Yes
//     No

Standard Numeric Format Strings

A standard numeric format string is a short code, often combined with a precision specifier (a digit indicating how many decimal places to show), that controls how a number is displayed. The ToString() method accepts a format string as an argument.

Format String Meaning Example
"F" Fixed-point, default 2 decimal places 19.99.ToString("F") → 19.99
"F3" Fixed-point with 3 decimal places 19.99.ToString("F3") → 19.990
"C" Currency, formatted for the current culture 19.99.ToString("C") → $19.99
"N" Number with thousands separators 23456.ToString("N") → 23,456.00
A culture represents the formatting conventions of a locale, such as which symbol represents currency and whether a comma or a period separates thousands. Format strings like "C" automatically adapt to the culture configured on the running system, which is why currency and date formatting should generally rely on "C" rather than hand-built strings.

➗ Operators and Math

Arithmetic Operators

C#'s binary operators require two operands, one on the left and one on the right. The core arithmetic operators are addition (+), subtraction (-), multiplication (*), division (/), and remainder (%).

Example: The Remainder Operator

int totalMinutes = 130;
int wholeHours = totalMinutes / 60;      // 2
int leftoverMinutes = totalMinutes % 60; // 10

The % operator, often called the modulus or remainder operator, returns what is left over after one integer is divided by another. It is commonly used to test whether a number divides evenly (a remainder of zero) or to break a total into smaller units, as shown above.

When both operands of the / operator are integers, C# performs integer division: the result is truncated to a whole number, and any fractional part is simply dropped rather than rounded. In the example above, 130 / 60 produces 2, not 2.1667. If either operand is a float, double, or decimal, the division instead produces a full floating-point result with a fractional part.
C# has no dedicated exponent operator. To raise a number to a power, call the Math.Pow() method, which takes the base and the exponent as its two arguments and returns a double. 
double cubedValue = Math.Pow(3, 3);
// cubedValue holds 27, since 3 raised to the 3rd power is 27

Operator Precedence

Operator precedence (also called the order of operation) determines the sequence in which parts of an expression are evaluated. Multiplication, division, and remainder are always evaluated before addition and subtraction, regardless of the order in which they are written. Parentheses override the default precedence and are evaluated first, from the innermost pair outward. When operators share the same precedence level, associativity determines whether they group left to right or right to left.

Example: Precedence Changes the Result

int resultA = 4 + 3 * 2;   // 10 (multiplication first)
int resultB = (4 + 3) * 2; // 14 (parentheses first)

Shortcut Assignment Operators

C# provides shortcut versions of the assignment operator that combine an arithmetic operation with an assignment in a single step.

Operator Equivalent To Name
x += y x = x + y Add and assign
x -= y x = x - y Subtract and assign
x *= y x = x * y Multiply and assign
x /= y x = x / y Divide and assign

Increment and Decrement Operators

The unary operators require only a single operand. The increment operator (++) adds 1 to a variable, and the decrement operator (--) subtracts 1. Both come in two forms based on where the operator is placed:

Prefix (++x)

The prefix increment operator changes the variable's value first, then that new value is used in the rest of the statement.

Postfix (x++)

The postfix increment operator uses the variable's current value in the statement first, then changes it afterward.

Example: Prefix vs. Postfix

int lapNumber = 5;
int reportedLap = --lapNumber;
// lapNumber is decremented to 4 first, then reportedLap is set to 4
Console.WriteLine("{0} and {1}", lapNumber, reportedLap);
// Output: 4 and 4

Comparison Operators

A comparison operator compares two operands and produces a Boolean result. Equality is tested with == (two equal signs, not one), and inequality is tested with !=.

A single equal sign (=) assigns a value; a double equal sign (==) compares two values. Confusing the two is one of the most common beginner mistakes in C#.

🔄 Type Conversion

When an arithmetic operation uses operands of different types, C# automatically converts the nonconforming operand or operands to a single unifying type before performing the calculation. This automatic process is called an implicit conversion, and a conversion that the compiler performs on its own, without you writing anything special, is described as happening implicitly.

Example: Implicit Conversion

int wholeLaps = 6;
double lapDistance = 0.25;
double totalDistance = wholeLaps * lapDistance;
// wholeLaps is implicitly converted from int to double before multiplying

An implicit cast is always safe because it moves a value from a smaller or less precise type to a larger, more precise one, so no information is lost. Moving in the opposite direction, from a type that can hold more information into one that holds less, requires an explicit cast, which you write yourself using parentheses around the target type.

Example: Explicit Cast

double averageSpeed = 7.85;
int roundedSpeed = (int)averageSpeed;
// roundedSpeed becomes 7; the fractional part is discarded, not rounded
Casting a double to an int truncates the decimal portion instead of rounding it. Casting 7.85 to int produces 7, not 8. If you need mathematical rounding, use a method such as Math.Round() before casting.

You explicitly write the target type in parentheses whenever you need to force a conversion the compiler will not perform on its own: (int), (float), and similar expressions all instruct the compiler to convert the value that follows.

🔤 Characters and Strings

The char Data Type

A char variable holds exactly one character, including letters, digits, symbols, and non-printing characters. C# represents characters using Unicode, a 16-bit coding scheme capable of representing characters from virtually every written language, not just the basic English alphabet.

A character literal is enclosed in single quotes. You can also specify a character using its hexadecimal Unicode value (base 16 notation) with the form \u followed by four hex digits.

Example: Declaring char Values

char gradeEarned = 'A';
char capitalA = '\u0041'; // also the letter A, written in hex

Escape Sequences

An escape sequence represents a special character, such as a new line or a tab, and always begins with a backslash.

Escape Sequence Meaning
\n New line
\t Tab
\\ A literal backslash
\" A literal double quotation mark inside a string
A quotation mark that needs to appear inside a regular string must be escaped with \", because an unescaped quotation mark would prematurely end the string. Raw string literals, covered next, offer a way around this.

Raw String Literals

C# 11 introduced raw string literals, written with three or more double-quote characters (""") opening and closing the string. Inside a raw string literal, quotation marks and backslashes are treated as ordinary characters, so you rarely need escape sequences at all.

Example: Raw String Literal

string announcement = """
Have you heard "Old MacDonald"?
""";
// The quotation marks around Old MacDonald need no escaping

The string Data Type

The string data type holds a series of characters. Strings in C# are immutable: once created, a string's contents cannot be changed in place. Operations that appear to modify a string, such as concatenation, actually produce a brand-new string.

Comparing Strings

Comparing strings with == checks whether two string variables hold identical text. To compare strings lexically, meaning in dictionary order so you can tell not just whether they are equal but which one comes first alphabetically, C# provides dedicated methods.

Method Purpose
Equals() Returns true if two strings hold identical text
CompareTo() Instance method; returns a negative, zero, or positive number showing lexical order relative to another string
Compare() Static method on the string class; compares two strings passed in as arguments
StartsWith() Returns true or false depending on whether a string begins with the specified text
StartsWith() is case-sensitive by default, so "Chocolate".StartsWith("ch") returns false while "chocolate".StartsWith("ch") returns true.

Example: Lexical Comparison

string oldName = "Anderson";
string newName = "Baxter";

int result = oldName.CompareTo(newName);
// result is negative, because "Anderson" lexically precedes "Baxter"

Extracting Part of a String

The Substring() method returns a portion of a string, starting at a given character position and, optionally, running for a specified number of characters. String positions are counted starting at zero.

Example: Substring()

string fullWord = "overflow";
string ending = fullWord.Substring(4);
// ending holds "flow", starting at position 4 through the end

🏷️ Enumerations

An enumeration is a type-safe, self-documenting set of named constants, defined with the enum keyword and placed in a class outside of any method. Being type-safe means the compiler only allows a value from that specific enumeration to be assigned to a variable of that type, preventing accidental use of an unrelated number. Being self-documenting means the identifier names themselves explain what the values represent, instead of relying on unexplained numbers scattered through the code.

Example: Defining and Using an Enumeration

enum RaceDistance
{
    FIVE_K, TEN_K, HALF_MARATHON, MARATHON
}

RaceDistance todaysRace = RaceDistance.TEN_K;

Behind the scenes, each member of an enumeration corresponds to an underlying integer value, starting at zero for the first member and increasing by one for each member that follows, unless you assign specific values yourself. Even so, you refer to enumeration members by name rather than by number, which is what makes the code self-documenting.

⌨️ Console Input

An interactive program is one that accepts user input while it runs and adjusts its behavior based on that input. A prompt is a message a program displays instructing the user what data to enter.

Reading Input

The ReadLine() method pauses a console program and waits for the user to type a line of text, ending when the user presses Enter. Whatever the user typed is returned as a string, regardless of whether the characters look like a number.

Example: Prompting and Reading

Console.Write("Enter the number of laps completed: ");
string lapsEntered = Console.ReadLine();

Converting Input to a Number

Because ReadLine() always returns a string, you must convert that string before you can use it in arithmetic. C# offers two common approaches.

The Convert Class

Static methods such as Convert.ToInt32(), Convert.ToDouble(), and Convert.ToByte() convert a value to the indicated type. Convert.ToByte() specifically converts a value to an 8-bit unsigned integer.

Parse() Methods

Numeric types provide their own static Parse() method, such as int.Parse() or double.Parse(), as an alternative way to change a string into a number.

Example: Converting User Input

Console.Write("Enter your finish time in minutes: ");
string timeEntered = Console.ReadLine();

// Using the Convert class
double finishMinutesA = Convert.ToDouble(timeEntered);

// Using the double type's own Parse method
double finishMinutesB = double.Parse(timeEntered);
Both approaches accomplish the same goal. Either double.Parse(ReadLine()) or Convert.ToDouble(ReadLine()) reads a line of console input and converts it into a usable numeric value in a single step.
